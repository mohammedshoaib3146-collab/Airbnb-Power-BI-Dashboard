# 🏠 Airbnb Market Analysis Dashboard — Power BI

## 📌 Project Overview

This project showcases an Airbnb market analysis dashboard developed using Microsoft Power BI. The dashboard presents visual insights into Airbnb listings and market patterns to support data-driven exploration.

## 🎯 Project Objectives

- Explore Airbnb listing and pricing patterns.
- Present key metrics through interactive-style visualizations.
- Compare listing characteristics and market trends.
- Communicate data insights through a clear dashboard layout.

## 🛠️ Tools Used

- **Microsoft Power BI** — dashboard development and data visualization
- **Data Visualization** — charts, KPIs, and visual reporting
